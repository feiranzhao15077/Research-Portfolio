# LowAlt-MD summary

_Portfolio summary derived from the Physics Model v2 mentor-facing materials._

---

## 🎯 Research question

LowAlt-MD asks whether low-altitude ground multipath changes only the overall echo magnitude or can change the normalized rotor micro-Doppler structure itself.

## 🔗 Evidence chain

The project follows the chain:

`path difference → element-wise phase → coherent interference → micro-Doppler structure → feature-domain shift → recognition and generalization boundary`

The project separates a physical mechanism bridge from a controlled recognition audit and a matched-budget multi-environment test.

## ⚠️ Scope and limits

The current evidence is synthetic. It uses a flat lossy ground, specular multipath and an isotropic point-scatterer proxy; it is not a measured radar validation and should not be described as a universal statement about all terrain or rotor targets.
